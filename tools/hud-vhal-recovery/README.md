# Восстановление HUD

Минимальная сервисная утилита для чтения и восстановления VHAL-свойства
`557847263`.

Приложение не выполняет запись автоматически. Кнопка восстановления:

1. читает и показывает исходное значение;
2. трижды записывает `1` с короткими интервалами;
3. через 700 мс повторно читает свойство и показывает результат.

Другие VHAL-свойства, FakeTeleNav и настройки приборной панели не изменяются.

Сборка:

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Результат: `build\hud-vhal-recovery.apk`.
